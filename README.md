# Manav AI Portfolio

A dark, high-end AI-engineering portfolio for Manav Runthala.

## Run locally

No build step required. Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Structure

- `index.html` — portfolio content
- `styles.css` — visual system and responsive layout
- `script.js` — cursor glow, reveal animations, typing terminal, project tilt
- `github-profile/README.md` — starter GitHub profile README
